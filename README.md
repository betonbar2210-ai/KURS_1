# Приложение для анализа банковских операций  

## Описание проекта
Приложение предназначено для анализа банковских транзакций, хранящихся в Excel-файле.  
Система генерирует JSON-данные для веб-страниц, формирует Excel-отчеты и предоставляет различные аналитические сервисы.

## Основные возможности
1. Веб-интерфейс
- Главная страница - отображение общей информации по картам, топ-транзакций, курсов валют и цен акций

- Страница событий - аналитика расходов и поступлений за выбранный период

2. Аналитические сервисы
- Анализ категорий с повышенным кешбэком

3. Отчетность
- Анализ трат по категориям


## Требования к окружению
* Python 3.14+

* Библиотеки: pandas, requests, pytest, yfinance

* Настройки в файле user_settings.json

### Настройка проекта
* Клонировать репозиторий

* Установить зависимости: poetry install

* Настроить переменные окружения через .env файл

* Разместить файл операций в директории data

### Основные команды
- Анализ транзакций: python src/services.py

- Формирование отчетов: python src/reports.py

- Тестирование: pytest tests/


## ВНИМАТЕЛЬНО ОЗНАКОМИТЬСЯ
    1. Для получения курса валют запрос на ЦБ РФ без API-ключа
    2. Установить зависимости poetry особое внимание на библиотеку 'YFINANCE' для работы котировок акций
